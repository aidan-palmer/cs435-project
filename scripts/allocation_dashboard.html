What do predicted, actual, and realized mean?

Predicted benefit: avoided CO₂ estimated using forecast electricity demand, the solar profile, and the emissions factor. This estimate determines the ranking.

Actual demand: the held-out electricity-demand values in the source dataset. For these ResStock homes, these are simulated demand values, not household meter readings.

Realized benefit: avoided CO₂ recalculated using that held-out demand and the same solar profile and emissions factor. It evaluates the prediction; it is still a modeled result, not measured emissions.

These saved runs count solar used by the household, with zero export credit. Benefits cover the stated evaluation period, not a full year or the system lifetime. A home without an installation has potential benefits shown here, not benefits delivered by this allocation.
